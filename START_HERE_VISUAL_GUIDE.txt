❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"Python not recognized after installation"
→ SOLUTION: Add Python to PATH
  1. Win+X → System
  2. Advanced system settings
  3. Environment Variables
  4. Add: C:\Users\YourName\AppData\Local\Programs\Python\Python311
     OR: C:\Program Files\Python311
  5. Restart all terminals

"QUICK_START.bat fails"
→ SOLUTION: 
  1. Verify Python: python --version
  2. Delete .venv folder: rmdir .venv /s /q
  3. Try again: .\QUICK_START.bat

"Port 8000 already in use"
→ SOLUTION:
  netstat -ano | findstr :8000
  taskkill /PID <PID> /F

"Database error"
→ SOLUTION:
  python verify_database.py
  (Shows detailed error information)
